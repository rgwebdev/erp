Моделирование финансов и времени

Это не факт, а картина «как может быть». Активности описываются один раз (статьи расходов и время), затем расставляются по неделям года. Суммы в тысячах тенге.

Дневная активность

Дела за день из таймера на телефоне. Данные загружаются из JSON, поле для вставки открывается кнопкой.
Вставляется экспорт приложения «Карточки времени» за период (schema kartochki-vremeni/export/v2) или за один день (kartochki-vremeni/day/v1).
Экспорт v2:
{
  "schema": "kartochki-vremeni/export/v2",
  "exportedAt": "2026-10-22T16:40:12+05:00", "timezone": "Asia/Almaty",
  "range": { "from": "2026-10-16", "to": "2026-10-22" },
  "projects": [ { "id": "k3f9a1", "name": "Чтение" } ],
  "sessions": [ { "id": "m1x2y3", "projectId": "k3f9a1", "date": "2026-10-22", "start": "...", "end": "...", "seconds": 1800, "running": false } ],
  "corrections": [ { "projectId": "k3f9a1", "date": "2026-10-22", "minutes": -3 } ],
  "daily": [ { "date": "2026-10-22", "projectId": "k3f9a1", "launches": 2, "sessionSeconds": 2400, "correctionMinutes": -3, "totalSeconds": 2220 } ]
}
Время дела за день = totalSeconds (запуски плюс коррекция). Дни, присутствующие в новом экспорте, заменяются целиком; дни без данных в экспорте не трогаются. Резервная копия приложения не подходит.

Дневник

Записи по дням. Двойной клик по дате создаёт запись, цифра в углу клетки открывает записи дневника за этот день. Название дневника вверху включает показ его записей на календаре и его последние 5 записей. Записи можно исправлять и удалять. Тексты хранятся только в этом браузере: в личное хранилище и технический журнал они не попадают.

Журнал сдвигов

Что сбило, что изменилось, что пересмотрено. Одна запись на любое событие, которое меняет курс.

База данных и вход (LifeERP)

Данные либо в браузере, либо в базе данных под вашим логином (email) и паролем, вместе не работают. Подключение работает на вашем хостинге; со страницы на claude.ai оно блокируется.

Технический журнал

Каждое действие в программе: создание, изменение, удаление и ошибки записи. Новые записи сверху. Журнал клетки открывается кнопкой в панели календаря.

LifeERP: где хранить данные?

Оболочка пуста. Данные будут храниться либо в этом браузере, либо в базе данных под вашим логином и паролем. Вместе оба варианта не работают.
